# `arbitrate-rs`

Rust types + traits for decision-making through voter consensus.

## Overview

Partially inspired by [Symfony's `Voters` system](https://symfony.com/doc/current/security/voters.html)

### Features

Provides support for attaching context/evidence to a voter's decision.

This allows for producing a rich report/breakdown of
logic evaluation for complex, recursive, or highly inter-dependent condition cases.
